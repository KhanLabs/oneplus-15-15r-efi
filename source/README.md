# Source Files

This folder contains model-specific EFI files.

---

## OnePlus 15

Expected file:

```text
ABL_with_superfastboot(oneplus15).efi
```

Location:

```text
source/oneplus15/
```

---

## OnePlus 15R

Expected file:

```text
(oneplus 15R)ABL_with_superfastboot.efi
```

Location:

```text
source/oneplus15r/
```

---

## Important

- Use the correct file for the exact model.
- Do not cross-flash between OnePlus 15 and OnePlus 15R.
- Check each file's SHA-256 hash against `SHA256SUMS.txt` in this folder before use.
- Files are provided as-is.
